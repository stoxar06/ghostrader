Overview

What it is, and what it honestly is not

A Python toolkit that analyzes Indian equities using technical signals and an AI macro engine, backtests strategies with brutal honesty, and surfaces the result through a conversational MCP layer.

📈

Technical engine

Indicators + every candlestick pattern + multi-timeframe confluence + risk + a no-look-ahead backtest. Deterministic and fast — zero LLM tokens.

🧭

Macro / AI engine

FII/DII-style cues, global markets & news → a market regime, via a free-first LLM router (Groq → Gemini → OpenRouter → Claude) with a daily cost cap.

💬

MCP analyst

Talk to the engine from Claude Desktop: ask for the briefing, a backtest, or the SIP XIRR of any stock — read-only, no trading.

The defining result

No strategy beat buy-and-hold

Across trend, mean-reversion, breakout, swing and the momentum factor — tested out-of-sample, net of Zerodha costs — nothing produced a real risk-adjusted edge. The backtest gate did its job: it stopped a losing system from ever touching real money.

Workflow

The validation-first build

Every step had to earn the next. The strategy never reached real money because the gate said no — which is exactly the point.

Build engine

Data, indicators, candlesticks, confluence & risk — all unit-tested.

Backtest gate

Replay net of costs with no look-ahead. Go / no-go decision.

Walk-forward

Calibrate on train, judge on unseen test. Result: no edge.

Sweep & benchmark

Trend, mean-rev, breakout, swing, momentum vs buy-and-hold.

Pivot honestly

Ship the analyst tool + SIP analyzer. Shelve live trading.

How it works

Two engines, by design

Technical path

On each completed bar — microseconds, no LLM:

  • Compute indicators (EMA, RSI, ATR, VWAP, Supertrend…)
  • Detect candlestick patterns (engulfing, hammer…)
  • Each signal votes; votes are accuracy-weighted → a score
  • Higher-timeframe trend must agree to fire
  • Risk sizes the trade; ATR stop, target, trailing, daily halt

Macro path

Pre-market & every ~15–30 min — slow, cheap:

  • Pull global cues (yfinance) + market headlines (RSS)
  • Free-first router tries Groq → Gemini → OpenRouter, then Claude
  • Synthesizes a regime: risk-on / neutral / risk-off + bias
  • Falls back to a deterministic regime when no keys / over cap
  • Caches by input hash — no LLM call when nothing changed

How to use it

Run everything with one command

Python 3.12. Free data works out of the box; LLM keys are optional (the briefing falls back to a deterministic regime).

Setup

# clone & install git clone https://github.com/stoxar06/ghostrader cd ghostrader python3 -m venv .venv && source .venv/bin/activate pip install -r requirements.txt cp .env.example .env # optional: add free LLM keys

Commands

python -m src # list all commands python -m src brief # market briefing python -m src sip # SIP/buy-hold + Nifty benchmark python -m src research # strategy sweep vs buy-and-hold python -m src momentum # momentum factor test python -m src backtest # single-pass backtest python -m src walkforward# out-of-sample gate python -m src serve # MCP server for Claude Desktop

Talk to it from Claude Desktop

Add the MCP server to Claude Desktop's config, then ask in plain English — “what's the market regime?”, “SIP XIRR of TITAN?”, “backtest RELIANCE”.

// claude_desktop_config.json { "mcpServers": { "ghostrader": { "command": ".venv/bin/python", "args": ["-m", "src.mcp.server"], "cwd": "/path/to/ghostrader" } } }

Configuration

  • config.yaml — tunables: instruments, strategy, risk, costs, LLM order & cap
  • .env — secrets (gitignored): Kite, Groq, Gemini, OpenRouter, Anthropic, Telegram
  • Free-first: most days cost ~₹0; paid Claude only as a capped fallback
